# 문서 스캐너

휴대폰으로 찍은 문서를 **자동으로 잘라 반듯하게 펴고, 그림자를 지워** 스캔본(이미지·PDF)으로 만드는 웹앱입니다.
모든 처리는 휴대폰 브라우저 안에서 하며, 사진은 어디에도 올라가지 않습니다. 인터넷이 없어도 동작합니다.

**앱 주소:** https://ahnjs5576-cyber.github.io/scanner/

## 홈 화면에 앱으로 설치

- **아이폰:** 사파리로 위 주소 열기 → 아래 공유 버튼(⬆️) → **홈 화면에 추가** → 추가
- **안드로이드:** 크롬으로 위 주소 열기 → 오른쪽 위 ⋮ → **앱 설치**(또는 **홈 화면에 추가**) → 설치

## 기능

- 촬영하거나 사진을 고르면 문서 테두리를 자동으로 찾아 스캔 (여러 장 한 번에)
- 컬러 · 흑백 · 회색조 · 원본 보정, 모서리 수동 조정, 회전
- 저장: 아이폰은 공유 시트로 사진 앱에 바로 저장, 그 밖에는 이미지(여러 장이면 ZIP) 또는 PDF 한 파일

이 저장소의 파일은 `ahnjs5576-cyber/ajs` 저장소의 `doc_scanner/pwa/build.py`로 만들어집니다. 직접 고치지 말고 그쪽에서 다시 만드세요.
